## 3. 分類検証の結論

* 季節は四季＋通年で過不足なし。
* テーマは初期6種で過不足なく、複数付与が常用された → テーマは複数選択を正式採用（`06 §6-7`）。
* タグは仮投稿から統制語彙（約30語）が確定（`06 §7-5`）。1投稿1〜3個で増殖なし。
* `温泉街` のように特定 Place に必ず付くタグは Place 属性へ寄せる（`06 §7-6`）。Post / Place 分離の必要性が実データで裏づけられた。
* 迷いの所在: テーマ自体より「テーマ/タグの境界」「桜素材の自然/日常の揺れ（005=日常・009=自然・010=日常）」「特定 Place に紐づくタグの扱い」。

⸻

## 4. 写真安全確認の結論

カバレッジ: EXIF/GPS は36/36枚、目視は36/36枚を確認（完了）。

### 4-1. EXIF / GPS

* **35/36 枚に GPS座標が残存**。除去済みは1枚のみ（IMG_8379＝撮影写真でなくイベントのチラシ画像）。
* 公開済み15件の画像も座標を保持しており、現状の元ファイルは公開不可。
* 対応方針: 公開経路には再エンコードした派生のみを置き、構造的に除去＋自動検査（`08 §11-4`、`12 §4-10`）。

### 4-2. 目視で見つかった要対応（優先順）

1. **trial-011（公開/C・IMG_7996）**: 鹿が主題だが背後が個人宅の居室窓＋私有地駐車場（生活導線）、車のナンバー一部。最優先でトリミングまたは非公開。
2. **trial-002・007（公開/B）**: 画像内のチェーン店・銀行の看板で同一交差点が特定可能。Bの地点ぼかしと矛盾。差し替え／トリミング／レベル運用見直し。
3. **trial-001（公開/A・IMG_7881）**: コンビニ駐車場で複数車のナンバープレートが読取可能。
4. **trial-018（下書き・IMG_8369）**: 識別可能な来場者多数。公開化前にマスキング/差し替え必須。

その他は城跡・桜・ダム・神社・料理・施設外観等で、人物・私有情報なし。

### 4-3. 教訓

公開レベルは投稿データだけでなく画像内容にも適用する必要がある（看板・私有地の窓で実質特定）。安全はチェックリストでなくシステムの性質にする（EXIF構造除去・人物公開ゲート）。`08 §5-2 / §11`、`12 §4-10 / §4-11 / §5` に反映済み。

## 5. 運用上の気づき

* **軽量投稿が未実証**: 軽量10本すべて本文が長文で、「写真1枚＋短メモ」での成立を検証できていない。
* **季節の偏り**: 春寄り（夏・秋ゼロ）。季節導線の検証は限定的。
* **公開レベルの偏り**: A17に集中。B〜Dの運用検証が弱い。
* **AI補助は前半中心**: 9件。後半はAIなしでも本文が長文で成立。AIなし運用の負荷感は本人評価が必要。
* **重複 Place / 近接投稿**: 清神社・郡山城跡で座標微差、002↔007がほぼ同型 → Place名寄せ・代表座標・束ね表示・重複許容ルールが要る。
* **撮影日の不整合**: trial-005 は CSV 撮影日（5/31）と EXIF（3/29）が不一致＝入力ミス疑い。
